# チャプター間リンクの書き方

ZennのBook形式では、別のチャプターへのリンク方法がいくつかあります。

## 1. 相対パスによるリンク（推奨）

同じBook内の別チャプターへテキストリンクを貼る場合、**チャプターのslug（ファイル名から`.md`を除いたもの）**を相対パスで指定します。

### 記述例

```markdown
<!-- 直前・直後のチャプターや別チャプターへの相対リンク -->
[第1章に戻る](./01-introduction)
[第3章へ進む](./03-conclusion)
```

### 実際のリンク表示
- [← 第1章に戻る](./01-introduction)
- [→ 第3章へ進む](./03-conclusion)

> **注意点**:
> - 拡張子 `.md` は含めず、`./チャプタースラッグ` の形式で記述します。
> - `config.yaml` の `chapters:` で定義したスラッグと一致させてください。

---

## 2. チャプター内の特定セクション（見出し）へのアンカーリンク

別チャプターの特定の見出しへ直接ジャンプさせることも可能です。

### 記述例

```markdown
[第1章のチャプター構成へジャンプ](./01-introduction#チャプター構成)
```

### 実際のリンク表示
- [第1章の「チャプター構成」セクションへジャンプ](./01-introduction#チャプター構成)

---

## 3. Zenn公開後の完全URLによるリンク（絶対パス）

Zenn上にデプロイ・公開された後は、ビューアの完全URLを使った指定も可能です。

### 形式
```markdown
[リンクテキスト](https://zenn.dev/[ユーザー名]/books/[book-slug]/viewer/[chapter-slug])
```

また、URLを単独行に置くことで**リンクカード**としても表示できます。

---

## 4. 自動生成されるナビゲーション（手動リンク不要な部分）

以下のナビゲーションはZennのシステム側で自動的に提供されるため、Markdown内に手動で目次や「前へ/次へ」を書く必要はありません。

1. **ビューアのサイドバー目次**:
   全チャプターの一覧と現在位置が常時表示されます。
2. **ページ下部のPREV / NEXTナビゲーション**:
   `config.yaml` で定義した順番に沿って、前後のチャプターへの移動ボタンが自動生成されます。
