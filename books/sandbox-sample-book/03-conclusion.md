# まとめと確認ポイント

## チャプター間リンクのポイントまとめ

| リンク種別 | 記法 | 用途・特徴 |
| :--- | :--- | :--- |
| **相対リンク** | `[リンク名](./chapter-slug)` | 同一Book内の別チャプターへ遷移（おすすめ） |
| **アンカー付き相対リンク** | `[リンク名](./chapter-slug#見出し)` | 別チャプターの特定見出しへ直接ジャンプ |
| **完全URL（絶対パス）** | `https://zenn.dev/.../viewer/...` | 公開後の個別URL・リンクカード表示 |
| **自動PREV/NEXT** | 記述不要 | `config.yaml` の並び順でページ下部に自動生成 |
